# 破门而入 2D · 北方特遣队（同人致敬版）

一个用**纯 HTML5 + Canvas 2D + 原生 JavaScript** 写的俯视角战术 RTT 小游戏，
玩法与机制对标 *Door Kickers 2: Task Force North*。

> 零依赖、零构建、零安装 —— 双击 `启动游戏.bat` 或直接打开 `index.html` 就能玩。

---

## 这是什么

Door Kickers 2 的核心是：**暂停 → 规划 → 执行 → 随时再暂停**。
没有回合、没有六角格、没有行动点。你像指挥一支真实的特警小队那样，
给每名队员画好路线、选定观察方向、设定破门工具，
然后按下空格，看着计划在几秒内展开 —— 出问题时立刻暂停、修正、再放。

本作把这套循环完整复刻了下来：

| 系统 | 实现情况 |
|---|---|
| 视野锥（FOV） | ✅ 队员 90°，普通敌 90°，顾问/SSI 110° |
| 视线遮挡 | ✅ 墙体/家具/关门挡视线；窗户、矮掩体**不挡视线**但挡移动与子弹 |
| 方向性掩体 | ✅ 只有从掩体朝向被打才减伤，侧后翼包抄可无视掩体 |
| 护甲 / 穿甲 | ✅ 6 档护甲（0~50），穿甲值 ≤ 护甲等级即被挡下并大幅减伤 |
| 破门工具 | ✅ 徒手 / 踹门 / 撬棍 / 断线钳 / 霰弹破门 / 爆破索 |
| 噪音传播 | ✅ 每种动作有各自的噪音半径，会引来敌人调查 |
| 敌人 AI | ✅ 15 种敌人：巡逻/调查/追击/交火/找掩体/盲射/侧翼/自杀/行刑/狙击 |
| 受击反应 | ✅ 被打中立刻转向弹源；看不见射手时循弹道方向搜过来，不会站着挨打 |
| 细分规划 | ✅ 路径节点可单独设朝向与动作（切角 / 固定角度 / 取消点 / 停顿 / 同速 / 蹲跑 / 换弹换枪 / 静默），可插入、删除节点 |
| 反应时间 | ✅ 队员 ~0.46–0.70s，叛军 1.5s+，老兵/顾问/佣兵更快 |
| GO Code 编组 | ✅ A/B/C/D 分组，可让小组同时行动 |
| 星级评定 | ✅ 按用时 + 伤亡 + 人质安全 + 目标完成度给 1~3 星 |
| 程序化地图 | ✅ 12 张固定种子地图，BSP 房间生成 + 门窗 + 可破墙 |

## 任务

共 12 关，分四个战役阶段，难度递进：

- **新兵入门** m01–m03 —— 熟悉视野锥、踹门、GO Code、人质救援
- **北方特遣队** m04–m06 —— 院子突袭、定时炸弹、行刑者倒计时
- **斩首行动** m07–m09 —— 逮捕高价值目标、对抗 110° 视野的顾问、自杀背心
- **深入敌后** m10–m12 —— 雇佣兵、重装兵、IV 级插板的 SSI 特战（专家难度）

**六种任务类型**：清剿 / 人质救援 / 终止处决（限时）/ 拆除炸弹 / 逮捕要犯 / 护送要员。

## 细分规划与切角

参考 **Door Kickers 2 的规划系统**做的节点级编辑。DK2 里相关的三个概念：

| DK2 概念 | 操作 | 效果 |
|---|---|---|
| **Slice the Pie**（切角） | Shift + 右键拖拽（紫色箭头） | 沿路径行走的**同时**持续转向，始终对准箭头所指的点 |
| **Strafe**（固定角度） | Ctrl + 右键拖拽（蓝色箭头） | 边走边保持某个**固定角度**，不随位置变化 |
| **Cancel point**（取消点） | 双击移动线 | 取消切角 / 强制朝向等持续动作，恢复正常行进 |

本作的对应实现：

- **切角** = `FACE.FOCUS`：锥始终指向世界里的一个**点**。走位时点相对队员的方位不断变化，
  所以锥会跟着扫过去 —— 这就是"切披萨"。绕门窗或拐角画一段弧线走位时最有用。
- **固定角度** = `FACE.HARD`：角度固定在世界坐标里，走位时锥不扫。
- **取消点**：走到该节点时解除切角、并把后续节点上的朝向标记一并清掉。

**每个路径节点都能单独设朝向**（不是只能设终点）：

- **Alt + 左键点路径线** 插入节点 —— 这就是"细分"。
- 点节点选中 → 节点编辑条弹出（切角 / 固定角度 / 取消点 / 清除 / 删除）。
- 选中后**右键拖拽**给该节点设方向，`[` `]` 微调 5°，`Del` 删除。
- 渲染上：**蓝色箭头** = 固定角度，**紫色箭头 + 扫过弧线** = 切角，**✕** = 取消点。

> 路径线绘制在战争迷雾**之后** —— 规划路径是玩家自己的图层，
> 如果画在迷雾之前，未探索区域的路线会被压暗到看不清，而规划恰恰最需要看清它。

### 路径节点动作（对齐 DK2 的右键菜单）

选中任意节点后，编辑条上可以给它挂动作：

| 动作 | 说明 |
|---|---|
| **蹲 / 站** | 到达后切换姿态（蹲下移动慢，但更难被命中） |
| **跑 / 走** | 到达后切换冲刺（跑得快，但会发出脚步声） |
| **换弹** | 到达后立刻换弹（可以规划成「边走边换弹」） |
| **换枪** | 到达后切换主 / 副武器 |
| **静默** | 到达后进入 Go Silent（跑动与破门噪音大幅降低） |
| **停下射击 / 不停下** | 看见敌人是停下打，还是边走边打 |
| **删除此点之后** | 对齐 DK2 的 *Delete path from that point onwards* |

**停顿 + GO Code 自动触发 = 同步突入**：用 `Shift + 左键` 在门口插「停顿」节点，
队员走到就停住；再按 `Shift + 数字` 打开该组自动触发，全组到位后自动一起进。
这就是 DK2 里最常用的多人同步破门手法。

**与友军同速**（`Ctrl + 左键`）：这一段跟着 8m 内最慢的**正在移动**的队友走，
避免一个人冲太快把队形拉散。只算正在移动的 —— 否则已经就位的队友会让全队停住。

### 与原版 DK2 的对照

| DK2 功能 | 本作 | 说明 |
|---|---|---|
| 基本 / Strafe / Focused 三种朝向 | ✅ | 黄 / 浅蓝 / 紫，语义与 DK2 一致 |
| Cancel point（取消点） | ✅ | DK2 是双击路径线，本作放在节点编辑条上 |
| Halt（停顿） | ✅ | `Shift + 左键点路径线` |
| Match speed（同速） | ✅ | `Ctrl + 左键点路径线` |
| Go Silent（静默） | ✅ | `Shift + F` 全体，或节点级设置 |
| Keep Moving / Wait for clear | ✅ | `Shift + 反引号` 全体，或节点级设置 |
| GO Code 自动触发 | ✅ | `Shift + 数字` |
| 蹲 / 跑 / 换弹 / 换枪 | ✅ | 节点编辑条 |
| Delete path from that point | ✅ | 「删除此点之后」 |
| 破门菜单（踹 / 开 / 撬棍 / 断线钳 / 霰弹 / 炸药） | ✅ | 点门弹出 |
| 窥视摄像头（spycam） | ❌ | 未做 |
| 狙击手支援 / 狙击镜 | ❌ | 未做（精确射手是普通单位） |
| 多人合作 / 聊天 / 涂鸦 | ❌ | 单机作品，不涉及 |
| 地图编辑器 | ❌ | 未做（12 张固定种子地图） |

> **关于「停下射击 / 不停下」的默认值**：DK2 的默认是**停下射击**（Wait for clear），
> 但本作原本是按「边走边打」调的平衡。A/B 实测（5 组种子）：停下射击 53/60、
> 边走边打 56/60 —— 所以**默认沿用后者**，想体验 DK2 手感按 `Shift + 反引号` 一键切换。

## 战术信条（技能树）

参考 **Door Kickers 一代的 Doctrine 系统**设计：

- **按武器类别分三棵树**，而不是按职业分 —— 任何队员只要手里拿那类武器就自动享受加成。
- **对全队所有队员生效**，不是单个队员养成。
- **点数来自小队等级**：每升 1 级得 1 点，等级上限 21（最多 20 点）。
- **节点有前置**，部分节点还要求"该树已投入 N 点"。
- **重置免费**，随时可以洗点换打法。

| 树 | 覆盖武器 | 代表节点 |
|---|---|---|
| **手枪系** | 手枪（含副武器） | 近距速射 · 精准射击 · 快速拔枪 · **双击** · 长距训练 · **莫桑比克** · 贴身轴线 |
| **长枪系** | 步枪 / 冲锋枪 / 机枪 / 精确射手步枪 | 近距交战 · 中距训练 · 依托射击 · **切换** · 长距训练 · **背刺** · **破掩体** · 静默 |
| **破门系** | 破门工具与战场技能 | 强力撬门 · 排爆训练 · 快速换弹 · **一枪破门** · 静默突入 |

经验来自任务结算：**胜利 120 XP + 每星 40 XP**，失败给 40 XP 保底（避免卡住无法成长）；
重复通关同一关只按 30% 计，防止反复刷第一关把整棵树点满。

> 几个节点的实际效果举例：**莫桑比克** —— 手枪连续命中同一目标的第 3 发必定暴击；
> **切换** —— 主武器打空时自动掏副武器而不是原地换弹；**一枪破门** —— 破门霰弹一枪击破上锁门
> （默认需要两枪）；**破掩体** —— 目标躲在掩体后时掩体减伤减半。

## 技术说明

- **纯前端**：没有服务器、没有 npm、没有构建步骤。所有逻辑跑在浏览器里。
- **A\* 寻路**：带权格子代价 —— 关门的代价高于开门，锁门更高，可破墙最高。
  这样队员/敌人能"穿过"关着的门（代价高），配合破门动作自然衔接。
- **Bresenham 视线**：逐格投射判断遮挡。
- **视野遮罩迷雾**：已探索（记忆）/ 当前可见 / 未探索 三态。
- **可复现**：所有随机（地图生成、AI 决策、命中判定）都走项目内置的
  种子随机数发生器 `ENG.rng(sim)`，同一关卡每次运行结果一致，便于调试与测试。

### 自检工具（开发用）

无头验证（不需要浏览器，跑得快）：

```bash
node _tools/selftest.js        # 机制单元验证 + 12 关模拟
node _tools/selftest.js m06    # 只跑某一关
node _tools/realplay.js        # 用"会停火射击的拟真 AI"跑全部 12 关
node _tools/realplay.js m01,m02
node _tools/uitest.js          # 用 Canvas 桩跑全部渲染路径，抓"静默不渲染"
node _tools/doctest.js         # 战术信条：等级/点数/前置/效果聚合 单元验证
node _tools/hitreaction.js     # 敌人受击反应：转身 / 还击 / 循弹源追击
node _tools/slicetest.js       # 细分规划与切角：锥是否扫动 / 取消点 / 插点删点
node _tools/verify_pen.js      # 穿甲矩阵 / 双向 TTK 核对
```

诊断开关（排查用）：

```bash
DK2D_INSTANT_BREACH=1 node _tools/realplay.js   # 把破门耗时还原成瞬间，隔离它对通关率的影响
DK2D_OLD_REPATH=1 node _tools/realplay.js       # 队员卡住后退回"直奔终点"的旧重寻路行为，A/B 对比
DK2D_FORCE_AUTOSHOOT=1 node _tools/realplay.js  # 默认改成 DK2 的"停下射击"，A/B 对比
DK2D_SEED_OFFSET=2 node _tools/realplay.js      # 平移关卡种子，判断某关是否"卡在某条随机轨迹上"
```

真实浏览器验证（零 npm 依赖，直接驱动本机已装的 Chrome/Edge）：

```bash
node _tools/shots.js           # 真实渲染并截图到 _shots/，同时收集运行时异常
node _tools/interact.js        # 派发真实鼠标/键盘事件，验证交互链路
```

`shots.js` 走 Chrome DevTools 协议（`--headless=new` + 内置 `fetch`/`WebSocket`），
`interact.js` 会断言「点选队员 → 拖拽画路径 → 队员沿路径移动」整条链路是否真的通 ——
这两个脚本能覆盖到纯 VM 测试碰不到的输入层。
