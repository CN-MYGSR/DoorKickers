破门而入 3

2D 俯视 · 即时战术 · 规划与执行

灵感来自 Door Kickers 2: Task Force North —— 没有回合、没有行动点，只有自由规划与实时执行。

核心机制
  • 视野锥 90°（顾问 110°），背后永远是盲区
  • 无遮挡视线 被墙、家具、关闭的门阻挡；窗只挡人挡不住视线
  • 掩体 只对掩体方向提供减伤，侧面与背后无效
  • 穿甲 0-70 制：穿甲值低于护甲等级则伤害大幅衰减
  • 噪音 踹门 7m、破门霰弹 25m、破门炸药 40m、消音枪 8m
  • 反应时间 普通敌人 1.5s，专家 0.5s，且视野扩至 120°

关键机制

  • 视野锥：队员 90°，普通敌人 90°，外国顾问 110°，专家难度敌人 120°。锥外目标必须先转身才能瞄准，转身速度由机动性决定。
  • 视线：墙、家具、关闭的门阻挡视线；窗户和矮掩体不挡视线但挡移动/子弹。
  • 掩体：只对掩体方向有效，默认 50% 减伤。绕到侧面或背后打就无效。蹲下额外提升。
  • 穿甲：0-70 制。M4 穿甲 32 打 III 级插板（30）刚好穿透；破片/手枪穿甲低，对重甲无效。
  • 噪音：会在半径内惊动敌人去调查。踹门 7m / 撬棍 12m / 破门霰弹 25m / 破门炸药 40m / 消音枪 8m / 死亡惨叫 4m。
  • GO Code：给队员分配 A/B/C/D 组，按 1 / 2 / 3 / 4 让同一组同时行动，用于多角度同步突入。
  • 断电：靠近配电箱规划动作可切断全楼电源，黑暗会大幅缩短视野，装备夜视仪的队员不受影响。
  • 自杀背心：贴近队员后引爆；被爆炸击杀时也会连锁引爆，可以清场也会炸死自己人。
  • 行刑者：看到同伴尸体、听到枪声、看到门被打开会提前处决人质。优先击杀。
  • 受击反应：敌人被打中会立刻转向弹源；如果看不见射手，会循着弹道方向搜过来 —— 不会站着挨打。从背后偷袭只能争取一两秒。
  • 切角（Slice the Pie）：Shift + 右键拖拽标一个点，队员会沿路径行走的同时持续把视野锥转向那个点 —— 锥会跟着"扫"过去。绕着门窗或拐角画一段弧线走位时，这是最安全的清角方式。Ctrl + 右键拖拽则是固定角度（Strafe）：角度在世界坐标里不变，边走边保持同一个朝向。
  • 细分规划：每个路径节点都能单独设朝向（切角 / 固定角度 / 取消点）。Alt / Shift / Ctrl + 左键点路径线分别插入 普通 / 停顿 / 同速 节点；点节点选中后可右键拖拽设方向、[ ] 微调 5°、Del 删除。蓝色箭头 = 固定角度，紫色箭头 + 弧线 = 切角，✕ = 取消点。
  • 节点动作：选中节点后可在编辑条上给它挂动作 —— 蹲 / 站、跑 / 走、换弹、换枪、静默、停下射击 / 不停下，还能删除此点之后的全部节点。节点下方会显示对应图标。
  • 停顿 + GO Code 自动触发：用 Shift+左键在门口插「停顿」节点，队员走到就停住；再按 Shift+数字 打开该组自动触发，全组到位后会自动一起进 —— 这就是标准的同步突入。
  • 星级：时间达标 + 无队员死亡 + 无平民伤亡 = 3 星。
  • 战术信条：主菜单里的技能树（参考 DK1 的 Doctrine）。按武器类别分手枪 / 长枪 / 破门三系，效果对全队生效。任务结算给小队经验，每升 1 级得 1 点，可免费重置。
